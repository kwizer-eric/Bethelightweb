# Static site images

Drop replacement photos here using these exact filenames (jpg, png, or webp — update the extension in `src/assets/siteImages.ts` if not `.jpg`).

| File | Used on |
|------|---------|
| `home-hero.jpg` | Home hero |
| `home-our-story.jpg` | Home “Our Story” panel |
| `home-volunteer.jpg` | Home Volunteer CTA |
| `home-support.jpg` | Home Support CTA |
| `about-foundation.jpg` | About parallax image |
| `about-community.jpg` | About secondary image |
| `every-kid-hero.jpg` | Every Kid Deserves It hero |
| `for-their-family-hero.jpg` | For Their Family hero |

Then set `USE_LOCAL_IMAGES = true` in `src/assets/siteImages.ts`.

CMS content (team / stories / children) is separate — edit those image URLs in the dashboard.
